# Publish knowledge after indexing and playground review

Knowledge uploads and edits produce a draft version that can be indexed and tested in the playground. Customer WhatsApp conversations use the selected published version, and an administrator publishes a ready draft explicitly. This protects customer answers when a document upload is incomplete, indexing fails, or a candidate price list has not yet been reviewed.

Immediate activation on upload was considered. Explicit publication adds version state and administration work, but provides a clear review point and rollback target. Publication switches the active version only after readiness checks; a failed job leaves the previous published version active.
